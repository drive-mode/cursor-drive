# Cursor Commands

Commands are invoked via `/command-name` in Cursor chat.

## Orchestration

| Command | Purpose |
|---------|---------|
| `/orchestrate` | Start parallel orchestration workflow; loads `orchestrate-parallel-work` skill |
| `/execute-plans` | Execute multiple plans with orchestration; see `execute-plans.md` |

## Drive Research

| Command | Purpose |
|---------|---------|
| `drive-research/01_generate-plan-catalog` | Generate plan catalog from drive-tech research |
| `drive-research/02_generate-workstream-plans` | Generate workstream plans |
| `drive-research/03_cursor-integration-plan` | Cursor integration plan |
| `drive-research/04_mcp-adoption-plan` | MCP adoption plan |
| `drive-research/05_verification-and-dedupe` | Verification and deduplication |
