# Cursor-Aligned Naming Recommendations

## Decision: Cursor Drive + Drive Mode

**Extension**: **Cursor Drive**
**Mode**: **Drive mode**
**Entry**: Status bar toggle + beforeSubmitPrompt hook (no @drive participant as primary)
**Tagline**: "Your AI driver. Voice-first, patient, version-aware."

---

## Cursor's Naming Patterns (from docs, changelog, features)


| Layer         | Examples                                          | Pattern                           |
| ------------- | ------------------------------------------------- | --------------------------------- |
| **Product**   | Cursor, Cursor Tab                                | Brand + optional qualifier        |
| **Features**  | Agent, Composer, Chat                             | Single-word, action/role-oriented |
| **Modes**     | Agent mode, Ask mode, Plan mode, Debug mode       | `[Noun] mode`                     |
| **Context**   | @codebase, @docs, @web                            | `@[lowercase]`                    |
| **Shortcuts** | Cmd+I (Composer), Cmd+L (Chat), Cmd+. (Mode menu) | Action-bound                      |


**Tone**: Professional, technical, minimal. **Drive** fits—action-oriented, badass.

## Why Drive Works for Pitching

1. **Fits Cursor vocabulary**: "Drive" aligns with Agent, Composer, Chat—action-oriented.
2. **Drive mode**: Status bar toggle; beforeSubmitPrompt routes when active.
3. **"Cursor Drive"**: Reads as a Cursor product, not a third-party add-on.
4. **"Drive mode"**: Fits naturally with "Agent mode", "Ask mode".
5. **Badass**: "Drive" = you're in the passenger seat; the AI drives. Memorable.
